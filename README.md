# Симулятор очереди на заправку

Абсурдный симулятор на Unity: часами стоишь в очереди на заправку, а у самой колонки бензин заканчивается.
Дизайн-документ — в [CLAUDE.md](CLAUDE.md) и [Docs/](Docs/).

## Как запустить (первый раз)

1. Установите [Unity Hub](https://unity.com/download), а через него — **Unity 6 LTS** (любая версия `6000.x`).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/mrdaaan1/Gas_station_queue_simulator.git
   ```
   Или через GitHub Desktop: *File → Clone repository*.
3. В Unity Hub: **Projects → Add → Add project from disk** → выберите папку репозитория.
   Если Hub напишет, что нужной версии Unity нет, просто выберите установленную у вас версию Unity 6.
4. Откройте проект. Первый запуск идёт несколько минут: Unity строит папку `Library`.
5. Сцена `Assets/Scenes/Prototype.unity` создастся и откроется сама.
   Если этого не случилось, выберите в верхнем меню **Gas Queue → Open Prototype Scene**.
6. Нажмите **Play ▶**.

После первого открытия Unity создаст файлы `.meta` и сцену. Закоммитьте их, это нормально.

## Как играть

1. Вы стоите в правой полосе городской дороги, в очереди на заправку. Подъезжайте за машиной впереди.
2. Не оставляйте большую дырку: машины из соседнего ряда моргают поворотником и влезают. Поджали — не влезут.
3. Можно выехать из очереди и попробовать встроиться дальше. Соседи это запомнят.
4. Аккуратнее: машины мнутся. Бампера и фары отваливаются, водители выходят ругаться.
5. Когда вы будете первым, перед вами опустят шлагбаум: «Бензин закончился». Ждите бензовоз.
6. Заезжайте к колонке, номер покажут вверху экрана. Заглушите мотор (I), выйдите (F).
7. Сходите в магазин. Если там очередь — встаньте в конец (E) и стойте на месте; без очереди кассир не обслужит.
   Ваша очередь — E у прилавка, оплатить (1). Вернитесь и вставьте пистолет (E у лючка справа сзади).
8. Когда бак полный, садитесь (F), заводите (I) и уезжайте через выезд обратно на дорогу.

Если долго бить машину (аварии, пинки, прыжки на крышу) — дым, капот и двери отваливаются, и игра проиграна.
Заправщик у первой колонки за 1000 руб. пропустит без очереди (или возьмёт деньги и забудет).

По дороге: наглецы вторым рядом (особенно таксисты у съезда), мужик с канистрами втридорога,
тётя с пирожками (лечат после драки), слух «на соседней есть бензин». Влезли без очереди или
стукнули машину — водитель выйдет пинать вашу машину. Выйдете — будет драка (ЛКМ).

## Настройки баланса

Во время Play выберите объект **Game** в окне Hierarchy. Все числа видны в компоненте **Game Settings**:
сколько машин впереди, как долго каждая заправляется, сколько длится «час» до завоза и т. д.

**Fast Test Mode** включён по умолчанию: всё идёт в 2 раза быстрее, и игра проходится примерно за 10 минут.
Выключите его, чтобы получить настоящие ~20 минут ожидания. Скорость можно менять и в меню паузы (Esc).

Изменения в Inspector во время Play не сохраняются. Чтобы сохранить, остановите игру
и поменяйте числа на объекте **Game** в самой сцене.

## Как устроен код

Весь мир строится кодом при нажатии Play, поэтому в сцене только один объект — **Game**.

```
Assets/
  Scripts/
    Core/    GameBootstrap (точка входа), GameManager (правила, касса, заправка, финал), GameSettings, GameInput
    Traffic/ TrafficManager (очередь, колонки, поток, вклинивания), NpcCar, Vehicle, CarDamage (вмятины, обломки), Geometry (маршруты, габариты)
    Player/  PlayerCar (езда, мотор, столкновения), CameraRig (камеры в машине и пешком), CarMirrors (зеркала заднего вида)
    People/  Human (человечек: ходьба, удары, прыжок, падение, синяки), Fighter (здоровье и драка), Brawler (возмущённый водитель), Vendor (продавцы),
             PumpCustomer (водитель NPC идёт платить), CashierLine (очередь в кассу), WalkerController (игрок пешком: прыжки, залезть на машину)
    World/   CityLayout (все координаты), CityBuilder (город и заправка), CarModels (2107, Rio-такси, Нива, Газель), CarFactory (машина игрока), TextureFactory, MeshFactory, StationProps
  Resources/Shaders/WorldText.shader — шрифт с учётом глубины (надписи не просвечивают)
    Audio/   SoundFactory (звуки генерируются кодом), Radio
    UI/      Hud, PauseMenu, MainMenu
  Editor/    PrototypeSceneCreator (создаёт сцену и меню Gas Queue)
```

Графика пока из кубов и цилиндров, текстуры (разметка, фасады) рисуются кодом, звуки синтезируются. Ни одного файла-ассета не нужно.
Человечки временные — их заменит модель с анимациями Mixamo.

## Собрать игру для друзей

- **Mac:** меню **Gas Queue → Собрать для Mac (.app)**. Через пару минут откроется папка `Builds/Mac` с `GasQueue.app`.
  Сожмите её (правый клик → «Сжать») и отправьте zip.
- **Mac из Терминала** (Unity должна быть закрыта): `cd ~/Gas_station_queue_simulator && bash Tools/build_mac.sh`.
  Готовый архив для друзей — `Builds/Mac/GasQueue-Mac.zip`.
- Перед любой сборкой (и при открытии проекта) редактор сохраняет материалы в `Assets/Resources/GasQueueGenerated` —
  без них Unity вырезает шейдеры, и в собранной игре всё розовое.
- **Windows:** **Gas Queue → Собрать для Windows (.exe)**. Нужен модуль *Windows Build Support (Mono)*
  (Unity Hub → Installs → ⚙ → Add modules). Отправляйте всю папку `Builds/Windows` в zip, не только `.exe`.
- Игра не подписана Apple, поэтому друзьям на Mac при первом запуске нужно:
  открыть `GasQueue.app` → «Отмена» → **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.
  Или в Терминале: `xattr -cr ~/Downloads/GasQueue.app`.
- Скорость игры берётся из объекта **Game** в сцене (по умолчанию ускорение ×2, ~10 минут). Её можно менять и в паузе.

## Если что-то не так

- **Ошибки про `UnityEngine.InputSystem` в консоли**: откройте *Edit → Project Settings → Player → Other Settings → Active Input Handling* и выберите **Both** (или **Input Manager (Old)**).
- **Нажимаю Play, а там пусто**: проверьте, что открыта сцена `Prototype` (меню **Gas Queue → Open Prototype Scene**).
- **Клавиши не работают**: кликните по окну Game, чтобы оно получило фокус.
- **Любая красная ошибка в Console**: скопируйте её текст целиком и пришлите Claude.

## Работа с Git

- Папки `Library/`, `Temp/`, `Logs/`, `UserSettings/` в Git не попадают (см. `.gitignore`).
- Модели, текстуры и звуки идут через **Git LFS** (см. `.gitattributes`).
  Один раз выполните `git lfs install`. В GitHub Desktop LFS уже встроен.
- Забрать изменения, которые Claude запушил в облаке: `git pull`. Unity подхватит их сам.
