Как запустить игру на Mac

Игра не заверена в Apple (это платная подписка разработчика), поэтому при первом запуске macOS её блокирует и пишет «Не удаётся открыть программу» или «Не удаётся проверить разработчика». Ниже три способа — пробуйте по порядку и остановитесь на том, который сработал.

Сначала

Распакуйте архив

  1. Дважды кликните по скачанному .zip — рядом появится папка с игрой.
  2. Перетащите игру (значок с колонкой «БЕНЗИНА НЕТ») в папку Программы. Можно оставить и в Загрузках — команды ниже найдут её в обеих папках.
Способ 1

Кнопка «Всё равно открыть»

Без Терминала. Работает, если macOS ругается на «неизвестного разработчика».

  1. Откройте игру двойным кликом. Появится предупреждение — нажмите Готово (или OK).
  2. Откройте меню → Системные настройки → Конфиденциальность и безопасность.
  3. Пролистайте вниз до раздела «Безопасность»: там будет строка про игру и кнопка Всё равно открыть. Нажмите её и введите пароль от Mac.
  4. Снова откройте игру и нажмите Открыть.

Кнопки нет, или ошибка «Не удаётся открыть программу» с одной кнопкой OK — переходите к способу 2.

Способ 2

Одна команда в Терминале

Снимает с игры пометку «скачано из интернета», возвращает права на запуск и заново подписывает её прямо на вашем Mac. Ничего устанавливать не нужно.

  1. Откройте Терминал: нажмите ⌘ + Пробел, наберите Терминал и нажмите Enter.
  2. Скопируйте команду и вставьте её в Терминал (⌘ + V), затем нажмите Enter: 
    find ~/Downloads ~/Desktop /Applications -maxdepth 3 -name "*.app" \( -name "*аправк*" -o -name "GasQueue*" \) 2>/dev/null | while IFS= read -r a; do xattr -cr "$a"; chmod +x "$a"/Contents/MacOS/*; codesign --force --deep --sign - "$a" && echo "Готово: $a"; done; echo "Поиск закончен"

    Должна появиться строка «Готово: …» с путём к игре. Строка «replacing existing signature» — это нормально.

  3. Откройте игру двойным кликом. Если macOS снова спросит — нажмите Открыть или сделайте способ 1.

Появилось только «Поиск закончен», без «Готово»? Значит, игра лежит в другой папке — используйте способ 3.

Способ 3

Те же команды вручную

Для любой папки. Каждую команду: скопировать → вставить в Терминал → перетащить игру из Finder прямо в окно Терминала (путь подставится сам) → Enter.

  1. Снять пометку «скачано из интернета»: 
    xattr -cr
  2. Вернуть права на запуск. После вставки перетащите игру, затем допишите в конце /Contents/MacOS/* без пробела: 
    chmod +x 
    /Contents/MacOS/*
  3. Подписать игру заново на этом Mac: 
    codesign --force --deep --sign -
  4. Откройте игру. Если спросит — Открыть.
Запустилось? Управление: W/S — газ и тормоз, A/D — руль, F — выйти из машины, Tab — подсказки, Esc — пауза. Делать всё это нужно только один раз.

Не помогло ни одно? Пришлите автору скриншот ошибки и модель Mac: → Об этом Mac (например, «MacBook Air M1, macOS 15»). Если в Терминале были красные строки — их тоже.
