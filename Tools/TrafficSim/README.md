# Симулятор очереди без Unity

Прогоняет настоящий код очереди и трафика (`Assets/Scripts/Traffic`, `CityLayout`, `GameSettings`)
на «заглушках» Unity и печатает, что происходит: сколько машин заправилось, кто где застрял.
Нужен .NET 8 SDK. Папка `Tools` лежит вне `Assets`, поэтому Unity её не видит.

```bash
cd Tools/TrafficSim
dotnet run -- 2 1 900          # ускорение 2, seed 1, 900 секунд
dotnet run -- 6 3 900 sneaky   # бот выезжает из очереди и встраивается ближе к заправке
```

Игрок здесь — бот: стоит в очереди, заезжает на выданную колонку, «заправляется» 30 с и уезжает.
