Сюда кладите свою музыку для гонки (mp3, ogg или wav).

В игре появится станция «Гонка FM» (R — переключить радио), в режиме гонки она
включается сама на зелёный светофор. Треки играют по очереди в случайном порядке.

Файлы из этой папки НЕ попадают в Git (см. .gitignore): музыка из Need for Speed —
чужая, её можно слушать у себя, но нельзя выкладывать в репозиторий и в игру для Steam.
